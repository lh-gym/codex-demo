添加新的面试记录

  1. 将新资料放入 items/topic-name/；需要保持稳定短链接的页面也可放在根目录。
  2. 共享图片、音频和下载文件放入 assets/，或与对应页面放在同一目录。
  3. 文件夹使用小写英文，单词之间使用连字符。
  4. 在 content/catalog.js 中添加一个项目对象。
  5. 确认 id 唯一，且 href 指向实际存在的文件。
  6. 本地检查首页搜索、筛选、页面链接和媒体播放。
